Privacy Policy

Last updated: September 2026

PlacementPrep is a free, independent student project. This page explains what data the app handles and where it goes. There is no advertising, no data broker, and no sale of personal data.

What stays in your browser

Your account, quiz progress, coding progress, interview experiences, saved jobs, and application tracker entries are stored using your browser's localStorage. This data is not sent to us or stored on any server we control. Clearing your browser's site data, or using a different browser or device, removes it. Use Export backup on the Dashboard to save a copy, and Import backup to restore it elsewhere.

What is sent to third-party services, and why

FeatureWhat is sentService
Resume Analyzer / Hiring Hub resume matchThe text extracted from your resume (the file itself is not uploaded)Google Gemini API
PrepAI chatbotYour chat messagesGoogle Gemini API
Aptitude quiz generationYour chosen category and difficultyGoogle Gemini API
Hiring Hub job listingsYour search keyword and city (if entered)Adzuna, Remote OK, Remotive, Jobicy
Coding Practice (C++)The code you write and runWandbox

These requests pass through our server, which does not log message content and applies rate limits to prevent abuse. Each provider has its own privacy policy governing how it processes what it receives.

Cookies and tracking

PlacementPrep does not use tracking cookies, analytics scripts, or advertising pixels. It does not sell or share personal data with advertisers.

Account security

If you create an account, your password is hashed before it is stored in localStorage, but this is a client-side profile, not a server-authenticated account. Do not reuse a sensitive password here. Continue as guest avoids creating any account at all.

Children's privacy

PlacementPrep is intended for college students preparing for job placements and is not directed at children under 13.

Changes to this policy

If this page changes, the "Last updated" date above will change too.

Contact

This is an open-source student project. Questions or requests can be filed as an issue on the GitHub repository.
